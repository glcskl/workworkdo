WorkDo — Мульти-арендная SaaS-платформа
WorkDo — масштабируемая B2B SaaS-платформа для автоматизации операционных процессов малого и среднего бизнеса. Архитектура построена на единой кодовой базе и физической изоляции клиентских данных по модели Schema-per-Tenant.
Поддерживаемые вертикали
Beauty & Wellness — расписание, онлайн-запись, клиентская база, учет услуг и аналитика для салонов красоты и SPA-центров.
Security Services — планирование смен, посты и маршруты патрулей, учет инцидентов, табель рабочего времени и управление персоналом для охранных предприятий (ЧОП).
Yacht Club — учет флота, бронирование стояночных мест, управление причалами, сезонные абонементы и экипажи.
Архитектурные принципы
Изоляция данных (Multi-tenancy): Общая схема PostgreSQL (public) хранит глобальные данные учетных записей и авторизации. Каждый бизнес изолирован в отдельной схеме базы данных со своими оперативными таблицами.
Чистая архитектура: Разделение логики на уровни Actions → Services → Repositories → Domain.
Server-Driven подход: Обработка бизнес-логики и мутаций через серверные механизмы фреймворка без промежуточного REST API.
RBAC: Гранулярное разграничение прав доступа по ролям пользователей внутри каждого арендатора.
Технологический стек
Frontend & Core: Next.js (App Router, Server Actions, React Server Components), TypeScript, Tailwind CSS, shadcn/ui.
Database & ORM: PostgreSQL, Prisma (для общих сущностей), Kysely (типобезопасный query builder для арендаторов).
Auth & Security: Сессии на базе токенов, ролевой доступ (RBAC), капча-валидация.
Инфраструктура: Модульная система миграций для динамически создаваемых схем, фоновая обработка транзакционных писем.
Быстрый старт
Требования
Node.js >= 18
PostgreSQL >= 14
Установка и запуск
Bash
# 1. Установка пакетов
npm install

# 2. Переменные окружения
cp .env.example .env
# Заполните параметры подключения к БД (DATABASE_URL) и секреты авторизации

# 3. Накатывание базовой схемы и миграций
npm run db:push
npm run public:migrate

# 4. Генерация типов данных
npm run generate:kysely

# 5. Запуск сервера для разработки
npm run dev
